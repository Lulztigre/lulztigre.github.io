// Abstract & Core Thesis

◈ FIELD NOTE

The vendor patch guarded the obvious sink and left the sibling controller running the same flaw. Patch archaeology, not patch worship.

// Reproduction (Cleanroom)

Fresh Joomla instance, stock plugin version, one curl. No authentication, no plugin configuration, no user interaction beyond a GET request with a self-minted signature parameter.

Disclosure timeline: report sent, vendor acknowledged in 36h, fix shipped in 2.4.3.2, CVEs reserved and published after coordinated embargo.
