Vulnerability Summary

During security assessment of iCagenda's administrative export workflows, a CSV Formula Injection vulnerability (CWE-1236) was identified in the registration export feature. When administrators generate CSV reports containing participant records, submitted registration fields (such as names, custom answers, and notes) are written to the output stream without sanitization of formula command prefixes.

If an unauthenticated or low-privileged registrant submits fields starting with formula characters (including =, +, -, @, or tab characters), spreadsheet engines (such as Microsoft Excel or LibreOffice Calc) interpret these values as active formula macros when the downloaded CSV is opened. This allows command execution (via DDE / system commands), outbound data exfiltration, and local file compromise on the administrative workstation.
